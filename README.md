# Portfolio

Personal portfolio profile built with Next.js, React, TypeScript, and Tailwind CSS.

## Local Development

Requirements:

- Node.js `18.17.0` or newer
- npm

Install dependencies:

```bash
npm ci
```

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Useful Commands

```bash
npm run lint
npm run build
```

Notes:

- `npm run build` downloads the Inter font through `next/font/google`, so it needs internet access at least once.
- `npm ci` currently reports npm audit vulnerabilities. Review them before production deployment.
